# Contributing

Bug reports and pull requests are welcome — integrations break when vendors
change their APIs, and reports from people running a bridge are the fastest way
we find out.

1. Read [AGENTS.md](AGENTS.md): the rules every bridge follows (standard
   protocols only toward the platform, nothing stored about the customer, no
   payload logs).
2. Open a pull request against `main` with tests next to the code and a
   changeset (`pnpm changeset`) for every published package you change.
3. **Sign the Contributor License Agreement.** On your first pull request the
   CLA bot posts a comment; reply with the sentence it asks for. One signature
   covers all your later contributions. The agreement is in [CLA.md](CLA.md):
   you keep the rights to your work and grant us a license to distribute it.
